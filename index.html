从规则到哲学：七条设计轴

七条设计轴从提示词规则出发，解释每款 Agent 被塑造成怎样的行动者、如何分配注意力与权限，以及把哪些资源视为稀缺。以下结论均为基于原文结构的编辑推断，并非厂商自述。

AXIS 01

受托关系

Codex 明确延续会话授权；Kimi Code 同时要求完整交付和范围约束。坚持完成与尊重范围可以并存；MiMo 当前捕获的交付则是一个结构化短标题。

依据：Codex CLI L11 · Kimi Code L49 · MiMo Code L5
AXIS 02

环境可读性

DSH 区分工作区、实现目录与正在运行的页面；OpenClaw 区分节点、Gateway 和用户会话。路径存在、工具可访问和模型已经看过是不同事实。

依据：DeepSeek Harness L39 · DeepSeek Harness L41 · OpenClaw L34
AXIS 03

上下文经济

Kimi Code 按字符预算续读长行，Pi 按需加载文档，OMP 先给代码结构摘要。OpenClaw 又把完整工具 Schema 转为按需发现；节省上下文不能成为猜测未读内容和接口的理由。

依据：Kimi Code L1108 · Pi L30 · Oh My Pi L652 · OpenClaw L8
AXIS 04

记忆制度

Claude 保存代码无法推导的背景；Hermes 把任务经验归入按需技能，但本次 one-shot 禁止写技能，不能转存常驻 memory。Claude Tag 还暴露私有类型与共享目录的张力，保存位置与实际访问范围必须一起核对。

依据：Claude Code L53 · Hermes Agent L423 · Claude Tag L1017
AXIS 05

证据闭环

Kimi Code 要求验证实际交付，Claude Tag 区分代码测试和真实使用路径，OMP 要求运行并观察结果。一次工具成功只证明对应步骤，不能自动证明整项任务完成。

依据：Kimi Code L51 · Claude Tag L38 · Oh My Pi L130
AXIS 06

权限与风险

授权来源、持续时间与作用域须分别检查。Codex 与 Kimi Code 承认持续授权，Kimi CLI 此捕获仍要求 Git 修改逐次确认；Claude 将难逆与对外动作的确认和持续授权例外并列。

依据：Codex CLI L11 · Kimi Code L45 · Kimi CLI L58 · Claude Code L30
AXIS 07

协作拓扑

空白上下文、完整继承、通知型与显式收集型任务各有交接方式。Codex 把上下文传递收敛为 none/all，OpenClaw 内部子任务留在父任务中，Hermes 依结果消费通道选择同步或后台；父代理仍承担整合与验收。

依据：Codex CLI L231 · OpenClaw L701 · OpenClaw L1058 · Hermes Agent L291

五个主题，一场横向对照

把 15 份提示词拆进同一坐标系后，浮现出的共识与分歧

目标机器

GOAL · 85 处批注

完成标准可以是完整工作产物、受控目标状态，也可以是一个忠实的短标题。Codex、DSH 与 OpenClaw 暴露目标工具；Hermes 要求真实执行证据；MiMo 当前捕获则必须返回结构化标题。范围约束与持续推进共同定义交付。

依据：Codex CLI L683 · DeepSeek Harness L29 · Hermes Agent L10 · MiMo Code L5

工程纪律

ENG · 155 处批注

验证方法随产物而变：真实场景、构建测试、浏览器交互和落盘哈希分别证明不同事情。Claude Tag 明确测试不能代替功能体验，Pi 用原文唯一匹配约束编辑；计划或工具调用完成仍不等于结果验收。

依据：Kimi Code L51 · Claude Tag L38 · Hermes Agent L968 · Pi L22

人格

PERSONA · 52 处批注

Codex 用坦率和可纠正的判断描述协作者，OpenClaw 借 SOUL 表达连续身份；MiniMax 当前以 MCode 对外自称，主会话保留需求解释与整合责任。人格与职责都是提示层设计，不是主观体验或商业动机的证明。

依据：Codex CLI L33 · OpenClaw L432 · MiniMax Code L26 · Pi L5

安全边界

SAFETY · 166 处批注

授权来源与作用范围需要一起判断：Claude 区分用户指令和粘贴内容，Hermes 填充 Vault 时原子核对 origin，OpenClaw 禁止代理自行执行用户审批命令。工具可见、结果可取回和动作已授权彼此不同。

依据：Claude Code L22 · Hermes Agent L176 · OpenClaw L90 · Kimi Code L29

工具·多智能体

TOOL · 300 处批注

独立调用可并行，前提依赖应顺序完成。Codex 的 exec、Hermes 的持久 Python 内核与 OMP 的 workpool 提供不同编排形式；通知、投递回执、可解析结果和验收通过是不同状态。

依据：Codex CLI L121 · Hermes Agent L372 · Oh My Pi L408 · MiniMax Code L989
